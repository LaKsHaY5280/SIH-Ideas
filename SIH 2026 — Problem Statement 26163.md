| **Problem Statement Title** | Security Assessment of the World Monitor application |
| **Description** | • Background The world Monitor application is a Web/ Mobile platform that provides users with real-time monitoring, analytics, and reporting features. The application handles user authentication, data visualization, API communication, and role-based access controls.<br><br>As a security analyst, the task is to evaluate the application's security posture and identify vulnerabilities that could compromise the confidentiality, integrity, or availability of the system.<br><br>• Description Conduct an authorized security assessment of the World Monitor application to:<br><br>1. Identify security vulnerabilities in the application.<br><br>2. Assess the potential impact of each vulnerability.<br><br>3. Demonstrate proof-of-concept exploitation in a controlled environment.<br><br>4. Recommend remediation measures to mitigate the identified risks.<br><br>• Scope The assessment should focus on:<br>• Authentication and session management<br>• Authorization and access control<br>• Input validation and data handling<br>• API security<br>• Client-side security controls<br>• Secure communication mechanisms<br>• Data storage and privacy protections<br>• Success Criteria The assessment is considered successful if:<br>• At least one valid vulnerability is identified and documented.<br>• Evidence supports the existence of the vulnerability.<br>• Risk and impact are clearly explained.<br>• Practical mitigation strategies are provided<br>• Expected Solution/Deliverables:<br><br>**For each vulnerability discovered, provide:**<br><br>• Vulnerability title<br>• Description<br>• Affected component<br>• Severity rating (e.g., CVSS)<br>• Steps to reproduce<br>• Proof of concept demonstrating the issue in a safe testing environment<br>• Business impact assessment<br>• Remediation recommendations constraints<br>• Testing must be performed only on authorized systems.<br>• No actions should affect production users or data.<br>• Exploitation should be limited to proof-of-concept validation.<br>• Compliance with applicable laws, policies, and ethical hacking guidelines is required.<br> |
